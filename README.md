# Mohit Goyal - Portfolio

A single-page, responsive portfolio built with plain HTML, CSS and a tiny amount of JavaScript. No build step is needed.

## Deploy on GitHub Pages

In Settings > Pages, choose **Deploy from a branch**, then `main` and `/ (root)`.

## Edit

Content and links are in `index.html`; visual styles are in `styles.css`. The contact link intentionally uses a personal email address rather than a phone number.
